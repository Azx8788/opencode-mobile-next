# OpenCode Mobile 2.0.0+56

Pick from six coding agents, schedule prompts that run while the app is closed, see and stop the servers your agent starts, and manage the Linux inside the app, with OpenCode 2 as the only OpenCode.

## What changed for you

- **Six agents**: Claude Code, Codex, Gemini, Kilo, Cline and OpenCode, whose free models need no API key.
- **Scheduled prompts** run at a time you choose, even with the app closed.
- **See and stop your dev servers**, and open them in an in-app preview.
- **A new Conversations widget** in five sizes that lets you Allow or Reject from the home screen.
- **Linux on your phone** you can manage, and a first setup that finishes in one go.

## Technical changes

### In detail
- **Scheduled prompts**: run a prompt at a time you choose, once or repeating, even with the app closed. You get a notification that opens the conversation, a history of each run, and you can pause, edit or delete a schedule. Find it in a conversation's menu under **Schedule a prompt**. A schedule for an existing conversation keeps that conversation's model, and a failed run says why in plain words.
- **Your dev servers, in one list**: under Files, **Development services** shows the servers your agent or you started, even ones started by hand in the terminal. Each has its port, a log you can read when the app can see it, a preview, and **Stop**, which asks first.
- **A manager for Linux on your phone**: under This phone, **Running** lists what is running, **Ports** shows who uses which port, **Storage** shows where the space went and clears downloaded packages, and **Reset Linux** erases and reinstalls it. Your projects are kept.
- **Setting up a new phone finishes in one go**: no more stopping at "Git and SSH" and asking you to continue or force stop.
- **Nothing is painted red**: failed or stopped replies, confirmation sheets and **Reset Linux** use calm neutral colours.
- **Widgets that settle**: after Allow, Reject or Stop, the widget stops saying "working" and shows the agent's latest reply.
- **A new Conversations widget in five sizes**: from a one-line strip to a full list of six conversations, in light and dark. When an agent needs you, the widget asks the question itself ("Run this command?") with the command, and lets you Allow or Reject on the spot. A working conversation shows how long it has been running and what the agent is writing now.
- **A Usage widget**: what is left on each Codex and Claude plan limit and when it resets, as clear bars, in a square or a wide size.
- **Every widget size is its own entry**: the widget picker lists each size separately with a full preview, so the widget lands at the size you chose.
- **"Done" in your conversations list**: a reply that finished while you were away shows a green ✓ Done; running ones show Working with a soft sweep.
- **The running step glows**: the step the agent is on lights up in the chat instead of a spinning ring.
- **Plain HTTP only when you say so**: a server address starting with http:// shows a warning and saves only after you choose "Allow HTTP for this server", for that exact address.
- **Self-signed HTTPS you can trust**: check a server's certificate fingerprint and trust it once. If the certificate changes later, the app stops before sending your password and asks you to re-check.
- **Servers on one computer stay apart**: two servers at the same address show their port, and "(secure)" for HTTPS, in every list and in the top bar.
- **Open your dev server from the chat**: tap a localhost link in a reply and it opens in an in-app preview, with Open in browser and Copy address.
- **A calmer Claude Code check**: a phone that is not signed in yet says "Sign in needed" with a Sign in button, not a failed check. Installing it shows the download in MB, and the bar never jumps back.
- **Resending a message settles at once**: after "Send again", the waiting card clears and the reply appears without leaving the chat.
- **A better terminal**: programs can copy to your clipboard, long links that wrap are tappable (open or copy), and underlines draw only where they should.
- **Kilo and Cline on your phone**: install them from the agent list next to Claude Code, Codex, Gemini and OpenCode, and pick one per conversation. Every agent and provider now shows its real logo.
- **Claude Code on this phone, smoother**: a signed-in Claude Code opens straight into the chat, pictures arrive as the right file type, localhost links it writes open in the preview, and a long silent tool call no longer reads as Claude Code not answering.
- **Repair a project's Git from New conversation**: a project whose Git cannot be read says so and offers a repair, and moving projects keeps their history readable.
- **First run asks for notifications during setup**, and a background stop that Android forced on an idle app no longer shows as a problem.
- **Back always goes somewhere**: a chat opened from its own notification no longer stacks a second copy, and Back from a chat with nothing beneath it returns to Conversations.
- **Sending from further up a conversation** brings you to your new message.
- **The finished notification** reads as a sentence, never ending on a colon, and a background connection stopped by a phone restart says exactly that.
- **OpenCode 2 only**: support for OpenCode 1 has ended.

### Added
- Scheduled prompts:
  - Durable schedules, one-time or repeating, each named by its prompt, with times in your locale format and pause, edit and delete. A finished one-time schedule reads "no more runs".
  - Run history per schedule, and an optional morning summary that comes before platform notices.
  - Runs with the app closed use bounded Android leases (WorkManager plus alarms). Profile deletion removes the schedule keys.
  - Available on OpenCode 2, Codex and Paseo connections with a project open.
- Development services: lists servers found on the phone's own Linux, including orphans started from a terminal. Detection no longer reads `/proc/net/tcp` (denied to apps); it takes ports from each process's command line, `*PORT=` variables and its log. Log view, Open preview and a confirmed Stop work from the same row.
- Linux manager for the in-app Ubuntu: Running (one row per program, true ages, helper processes grouped), Ports, Storage, Packages (search, install, remove) and Reset Linux.
- Terminal: clipboard copy requests ("Copied to clipboard" note), tappable wrapped links with an open or copy sheet, correct partial underlines, and a `claude` launcher.

### Changed
- OpenCode 1 is removed. OpenCode 2, direct Codex and Paseo remain. Legacy health responses are rejected at connect with an upgrade message.
- No red anywhere: destructive rows and sheets are neutral, and a declined tool call reads "You declined this".
- The Claude Code phone check treats a signed-out phone as "Sign in needed", not a failure.
- Reset Linux saves a marker before erasing. A refusal before erasing says "Nothing was erased"; a reset interrupted by closing the app finishes by itself on the next start and opens the setup progress.

### Fixed
- Chat routes are named per conversation, so an alert for the open chat no longer pushes a duplicate; a chat with nothing beneath it leaves for `/home` when the app declares it.
- The built-in Linux names Android's supplementary groups on every guest launch, so terminals no longer print "groups: cannot find name for group ID".
- A send while scrolled away from the latest message follows the new bubble to the bottom.
- Resume clears the Paseo lock a killed helper left behind.
- Fresh on-phone setup: the installer's ownership check treated a process that exited mid-read as an unknown writer and stopped the install. Exits are now tolerated, steps retry, and package repair reinstalls at the version the archive offers.
- "Could not read Linux" while a background server runs: processes whose parent exited are followed through their tracer, and Linux reads retry a passing failure first.
- A finished earlier setup held in memory no longer makes the start screen say "ready" after Reset Linux.
- This phone's installed list no longer says "Could not check" right after setup on a working Linux.
- Scheduled prompts compare stored run times as instants, so a run no longer fails on a time-zone mismatch.
- Widget actions reconcile with the server afterwards; the idle widget card shows the model and last activity.
- Scheduled runs over a plain-HTTP or self-signed server honour the consent and the trusted fingerprint, so a closed-app run no longer fails with "The agent could not be reached". Tapping its notification opens that run's conversation.
- After an explicit resend the chat refetches the conversation, so the queue card and the transcript agree without reopening.
- The Claude Code install bar is driven by measured bytes only (indeterminate until the size is known, never backwards).
