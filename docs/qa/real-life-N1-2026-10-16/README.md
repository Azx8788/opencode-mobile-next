## Failures (reproduction)

1. **N1-4 / dev services miss a running server.** Terminal (Built-in Linux): `cd /root/projects/my-app && (python3 -m http.server 8765 >/dev/null 2>&1 &)`. Files > Development services (project my-app) > menu > refresh. Expected "Also running" with Port 8765, Logs, Open preview (directory listing), Stop with a confirm. Got "No dev commands yet" only.
2. **N1-5 Running fails while a background server is up.** Same server; This phone > Linux > Running. Expected the list. Got "Could not read Linux" twice (Try again did not help); it worked after the server was killed. Not proven to be the cause, but it is the only change.
3. **N1-5 Reset Linux ends in an error and a contradictory home state.** This phone > Linux > Reset Linux, type Reset, confirm. Expected erase and reinstall, or a clear failure with a way forward. Got the runtime removed in 4 s, then "That did not work: That didn't work.", no reinstall, and "ready" next to "isn't answering". Copy also doubles ("did not work: That didn't work").
4. **N1-6 idle Conversations card** lacks model and last-active and clips its body (picker preview has the same short layout).
