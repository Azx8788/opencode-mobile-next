Claude Code on your Android phone.

No computer. No Termux.

OpenCode Mobile installs its own Ubuntu inside the app and runs Claude Code and OpenCode there. Ask for a change, watch it work, approve what it wants to do. Prefer your computer? Connect to the agent running there instead.

Act on your agents from the home screen, schedule a prompt for the morning, and see your dev server in the app, in a much smaller download.

Home-screen widgets that settle

Allow a request, reject it or stop a reply without opening the app. Afterwards the widget stops saying the agent is working and shows its latest reply. The idle card shows the model, the last activity and an Open button. To allow with the app closed, turn on "Stay connected in the background".

Scheduled prompts

Run a prompt at a time you choose, once or repeating. Each schedule keeps a history of its runs, and an optional morning summary tells you what ran while you were away. Android may delay or stop background work, so the app explains the battery setting that matters.

Preview your running app

Tap a localhost link in a reply and your dev server opens inside the app, with reload, open in browser and copy address. It loads only that one address; anything else opens through the app's external-link check.

Smaller, steadier first hour

There is now one download for each processor type: about 36 MB for most phones instead of 105 MB. A message the app could not confirm is kept for you to review and is never sent twice. You can connect to a plain-HTTP server after an explicit yes, or pin a self-signed certificate. OpenCode 2 is the only OpenCode the app supports now.

Questions

Is this the official OpenCode or Claude Code app?

No. OpenCode Mobile is an independent community project. It is not built, maintained or endorsed by the OpenCode team, and it is not affiliated with Anthropic. It was built with substantial AI assistance.

What runs where?

On this phone, the app installs Ubuntu inside itself and runs OpenCode 2 and Claude Code there; they use your phone's processor and memory, and their projects live inside the app. Or choose your computer: the app then connects to OpenCode 2 there and your files stay on that computer. Models always run at the provider you pick, whichever way you choose.

Which agents work?

Claude Code and OpenCode are the ones to start with. Codex, Gemini CLI, Qwen Code, Goose and Pi use the same on-phone path, but they are newer and have not yet been checked on a physical phone.

Can I schedule a prompt?

Yes, from the next release. Pick an agent, write the prompt and choose a time, once or repeating. Each run is kept in the schedule's history, and an optional morning summary lists what ran. Android limits background work, so a run can start late, and a long job on the phone is not guaranteed to finish.

Can I see the app my agent is building?

Tap a localhost link in a reply and the running dev server opens in a preview inside the app. For a server on your computer, the dev server must listen on 0.0.0.0 so the phone can reach it.

Does it connect to a server without HTTPS?

After an explicit yes for that server, it connects over plain HTTP, which sends everything unencrypted, so use it only on a network you trust such as your own Tailscale. For a self-signed HTTPS server you can check its certificate fingerprint and pin it; if the certificate later changes, the app blocks the connection until you verify the new one.

Does it still support OpenCode 1?

No. The app supports OpenCode 2 only. A phone that ran OpenCode 1 inside the app moves to OpenCode 2 and keeps its conversations; if the move cannot finish safely, the original data stays on the phone. A remote OpenCode 1 server shows how to upgrade it.

Does it cost anything?

The app is free and open source under the MIT license. It is not a hosted service and includes no model subscription: bring an API key or sign-in for the provider you want, or try OpenCode's free model.

What about my data?

The app talks to the servers you choose and to nobody else about your work. Passwords stay in Android's keystore, voice is transcribed on the phone, and a diagnostic report is sent only when you send one, with secrets removed. Logos of agents and common providers are bundled in the app; the rest are downloaded from models.dev by provider name and cached. The app has no analytics library. Read the privacy notes.

What phone do I need?

Android 8 or newer. Running agents on the phone needs a 64-bit phone; about 2 GB of memory works, slowly. From the next release the download is one file per processor type, about 36 MB for most phones (the universal file stays larger). The first setup then downloads about 210 MB of Ubuntu and tools, so Wi-Fi is best.

How do I get updates?

Install the APK from GitHub Releases, or add the repository to Obtainium. Updates install over the old version and keep your saved servers and settings, because releases share one signing key.
